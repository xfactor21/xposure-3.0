## 🌟 Key Features

### 🌐 20 Omni-Channel Platform Matrix
Seamlessly bridge 20 networks across social, developer, marketplace, and creator ecosystems:
- **Social & Media**: Instagram, TikTok, LinkedIn, YouTube, X (Twitter), Facebook, Pinterest, Twitch, Spotify, Threads, Bluesky, Mastodon.
- **Developer & Technical**: Reddit, GitHub, BitHub, Discord, Vercel.
- **Creator & Commerce**: Etsy, Substack, Product Hunt, Medium.

### 🧠 Zero-AI Deterministic Brand Studio
A mathematically rigorous brand-assistance engine with **zero external AI calls**:
- **Flesch-Kincaid Reading Ease**: Real-time readability index calculation (target 60–80).
- **Hook Velocity Engine**: Points for pattern interrupts, specific numerical hooks, and curiosity loops.
- **Forbidden Lexicon Detection**: Highlights overused marketing buzzwords with recommended green alternatives.
- **Combinatorial Copywriting Blueprints**: Instant algorithmic generation across PAS, AIDA, Contrarian, and Teardown frameworks.

### 🤖 Model Context Protocol (MCP) Server
A zero-dependency Node.js MCP server operating over `stdio`:
- **7 Native Tools**: `xposure_list_platforms`, `xposure_schedule_post`, `xposure_brand_audit`, `xposure_generate_hook`, `xposure_get_analytics`, `xposure_get_idea_board`, `xposure_add_idea`.
- **1-Click Auto-Installers**: Double-click `mcp-server/install.bat` (Windows) or run `./mcp-server/install.sh` (Mac/Linux) to configure Claude Desktop or Cursor automatically.
- **Zero Hosting Required**: Operates 100% locally on your computer with zero monthly fees or open ports.

### 🎨 macOS Floating Dock & Adaptive FAB
- **Dynamic Bottom Dock**: Quick hotkeys (1-9), tooltips, and fluid hover magnification.
- **Adaptive Draggable FAB**: Brand aperture emblem button with one-click access to the Top 5 recommended actions.

## 🚀 Quick Start

### 1. Run Web App Locally
```bash
# Clone the repository
git clone https://github.com/xfactor21/xposure-3.0.git
cd xposure-3.0

# Install dependencies and start
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Configure MCP for Claude Desktop or Cursor
```bash
# Windows
.\mcp-server\install.bat

# macOS / Linux
chmod +x ./mcp-server/install.sh
./mcp-server/install.sh
```

## ☁️ Deploy to Vercel

Xposure 3.0 is optimized for zero-config Vercel deployment:
1. Go to [vercel.com/new](https://vercel.com/new).
2. Import `xfactor21/xposure-3.0`.
3. Click **Deploy**.

Included in the repo is [`vercel.json`](./vercel.json) pre-configured with SPA route rewrites, production caching, and security headers.
